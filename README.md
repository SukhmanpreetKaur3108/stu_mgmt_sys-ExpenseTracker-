# stu_mgmt_sys-ExpenseTracker-
**Overview**
A beginner-friendly Python Expense Tracker Application that stores expense records in a CSV file.

**Features**
1. Add new expenses
2. View all recorded expenses
3. Calculate total amount spent
4. Display category-wise spending
5. Store data permanently in expenses.csv
6. Handle invalid amount input gracefully
7. Expense Details

**Each expense contains:**
1. Date
2. Category
3. Amount
4. Optional Note
5. Concepts Used
6. Python Functions
7. Lists and Dictionaries
8. CSV File Handling
9. Exception Handling
10. Loops and Conditional Statements
11. User Input
12. How to Run

Run the Python program. A menu will appear where you can choose to add expenses, view expenses, see the category-wise summary, or exit.
The expenses.csv file is automatically created when the program runs.

**Learning Outcome**
After completing this assignment, I learned how to use Python functions, handle CSV files, store and retrieve data, handle invalid input using exception handling, and create a simple menu-driven application.
